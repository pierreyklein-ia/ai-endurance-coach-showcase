# AI Endurance Coach — v0.52.5

**En ligne gratuitement : [GUIDE_SERVEUR.md](GUIDE_SERVEUR.md) (Oracle Cloud Always Free, Docker + Caddy HTTPS) · Sur ton Mac : [GUIDE_APP.md](GUIDE_APP.md) (installer l'application : `bash install.sh` puis `bash start.sh`) · [GUIDE_PILOTE.md](GUIDE_PILOTE.md) (options : Google Agenda, archive Strava) · [GUIDE_TEST.md](GUIDE_TEST.md) (démos hors application).**

Le canal est une **application web installable (PWA) avec chat intégré** (v0.9). v0.11-v0.12 : parcours d'accueil d'un nouvel athlète — connexion Strava dans l'app (API Strava officielle, OAuth), bilan des données, question sur l'échéance, plan proposé puis ajusté en conversation (le LLM extrait les demandes, le code recalcule le plan dans ses bornes de sécurité). v0.15 : questions sur le quotidien avant le plan (repos, renfo, autres sports, Strava et cardio, vacances), séances de renfo dans le plan, 7 fiches scientifiques de plus (force, blessures, cardio, récupération). v0.16 : sauvegarde quotidienne (coach/backup.py, deploy/restore.sh) vers la VM et Oracle Object Storage. v0.17 : mémoire de l'athlète (ce qu'il a dit + plan validé, affichés dans État, donnés au coach, sauvegardés avant toute remise à zéro) et mises à jour automatiques (deploy/update.sh). v0.18 : historique Strava sur 5 ans (pages de 200, rattrapage unique des comptes existants), profil long terme dans le bilan et pour le coach (records, ultras, plus grosses semaines, coupures), plafond de volume tiré de l'historique. v0.19 : onglet Progrès (coach/progress.py) : forme, fatigue et fraîcheur avec projection du plan jusqu'au jour J, cumuls 7 jours glissants, chronos estimés 5 km → marathon et temps des objectifs dans le temps, efficacité aérobie, semaines (monotonie, régularité), historique complet des activités. v0.20 : profil du coureur en radar (coach/radar.py), 7 notes sur 10 mesurables avec une montre (puissance aérobie, endurance de vitesse, durabilité par découplage FC/allure, caisse, robustesse, spécificité, force) avec l'évolution sur 3 mois ; économie de course et métabolisme signalés comme non mesurables sans laboratoire. v0.21 : dictée dans le chat (bouton micro) : reconnaissance du navigateur en direct, sinon transcription sur le serveur (coach/stt.py, Whisper local via faster-whisper) ; le texte reste modifiable avant l'envoi. v0.22 : base de connaissances portée à 35 fiches (force lourde et amplitude du squat, trap bar, travail par contraste, ischios et Nordic curl, sommeil, stress, surentraînement, nutrition dont ultra et entraînement de l'estomac, RED-S) ; classement des fiches par nombre de thèmes communs puis rareté du thème ; un retour de séance reste enregistré même si le coach ne répond pas ; correction : une date « 28/10 » n'est plus lue comme une douleur 10/10 (mode hors ligne). v0.23 : activités de l'onglet Progrès : 5 par défaut, « Voir plus », recherche (nom, mois, date, « 50 km ») ; plus de barre de défilement inutile dans le champ du chat. v0.24 : carrière (coach/career.py) : 62 trophées en 6 familles qui rapportent de l'XP (jalons, vitesse sur effort plat vérifié, endurance et D+, force avec charges déclarées, régularité en semaines, intelligence sans pic de charge), XP par séance du plan validée, niveaux à seuils doublés (20, 40, 80…), carrière reconstruite depuis l'historique, avatar personnalisable dont l'équipement et le décor évoluent avec le niveau (bouton en haut à gauche). v0.25 : corriger une échéance dans le chat après l'accueil (« c'est pour 2027 », « enlève le semi », « ajoute le trail de… ») : échéances mises à jour, date recherchée pour la bonne année, plan recalculé proposé (« Ça me va » / « Garder l'ancien plan ») ; la recherche de course respecte l'année demandée. v0.26 : séances bonus facultatives (une par semaine, charge 0, +4 XP) ; question route / trail / les deux à l'accueil ; renfo et trail de l'API Strava correctement reconnus (WeightTraining, Crossfit, TrailRun…, rattrapage des activités déjà importées) ; série « à la Strava » (semaines avec au moins une activité) ; 76 trophées ; niveaux plus durs au début (50, 100, 200…) et sans maximum ; robustesse du radar remise à 0 après 14 jours d'arrêt, +1 par mois ; repli automatique en mode simplifié quand Claude est indisponible (limite, surcharge, crédit) ; image de l'avatar par Gemini (« Nano Banana », facultatif, GEMINI_API_KEY).

Orchestration LangGraph : **1 LLM conversationnel + outils déterministes**.

```
coach/
  schemas.py        contrats Pydantic entre nœuds (sorties LLM structurées)
  triage.py         front-line frugal : règles, lexique red-flag, urgence (0 token)
  load_engine.py    nettoyage FC (Hampel, cadence lock), hrTSS, repli sRPE, PMC CTL/ATL/TSB/ACWR
  rules_registry.py registre versionné des seuils (statut validated / literature / placeholder)
  guardrails.py     règles déterministes : ACWR 4 zones, douleur, maladie, rattrapage, affûtage
  classifier.py     "Système 1" : routeur calibré à seuils asymétriques, adaptateur JEV, consentement
  checkpoint.py     sérialisation des checkpoints LangGraph (liste blanche des types)
  pacer/            Race Pacer : FIT/GPX/Strava -> courbe pente-vitesse perso -> Monte Carlo -> prévision gelée
    course.py       parcours trouvé par le système : sources (licence), validation distance/D+, ravitos, arrêt moyen unique
    calibration.py  effet de l'intensité (vitesse ∝ FC^γ), courbe FC-durée, backtest leave-one-out
    strava_io.py    flux Strava (connecteur officiel, usage personnel)
    athlete_store.py profil athlète calibré en JSON
    predict.py / calibrate.py  commandes : prévision gelée / calibrage depuis FIT-GPX-Strava
data/races/         catalogue de courses (Diagonale des Fous 2026 : 35 points, 15 ravitos)
data/athletes/      profils calibrés (pilote.json : données personnelles de l'athlète pilote)
experiments/strava_perso/  test sur données réelles + prévision Diag 2026 gelée
  rag.py            Agent Expert = retrieval sourcé, sans génération
  llm.py            port LLM : Anthropic (tool use forcé + cache) / Mock
  graph.py          StateGraph : triage -> extract -> evidence -> coach <-> guard -> confirm/fallback -> calendar
  app.py            point d'entrée canal-agnostique (interrupts avant triage, trace des nœuds)
  sandbox.py        athlète de démo + LLM heuristique hors-ligne + agenda en mémoire
  demo.py           simulateur de conversation en terminal (hors-ligne ou --claude)
  adapters/calendar.py  Google Calendar idempotent (agenda dédié en prod, agenda principal en pilote ; n'écrit que ses événements étiquetés)
  adapters/google_auth.py  OAuth Google « appli de bureau » (jeton local, droits 600)
  pilot/            mode pilote mono-athlète : SQLite local (~/.ai_coach), import FIT/archive Strava,
                    synchro Strava via le connecteur MCP officiel (usage personnel §3.5), affûtage déterministe,
                    CLI `python -m coach.pilot`
  web/              v0.9 application installable : API FastAPI (session signée, vues Aujourd'hui/Semaine/État,
                    validation de séance avec RPE, chat branché sur le graphe, import FIT, Web Push, rappels),
                    interface statique sans build (static/), CLI `python -m coach.web serve | import-carnet | push-test`
  diagnosis.py      bilan d'un nouvel athlète depuis son historique (volume, trail, qualité, référence, récupération)
  knowledge.py      base de connaissances : 12 fiches de synthèse sourcées (Seiler, Stöggl, Casado, Billat, Millet, Saugy…) pour le RAG et l'accueil
  race_lookup.py    recherche d'une course (recherche web Claude, sinon catalogue data/races/catalog.json), toujours confirmée par l'athlète
  onboarding.py     premier bloc (récupération, reprise, vitesse), préférences négociées, extraction FR, messages
  pilot/strava_api.py    API Strava v3 : OAuth « Connecter Strava » (state anti-CSRF, portée activity:read_all), jetons rafraîchis, synchro incrémentale (FC moyenne, flux FC des 30 sorties récentes, quota 429)
  pilot/carnet.py   import du Carnet VVX (export JSON) : séances, retours, focus et bilans de semaine
finops.py           modèle de coût par athlète, hypothèses explicites
eval/               banc de test du triage (matrice de confusion pondérée par le coût)
tests/              103 tests (accueil d'un nouvel athlète, application web, graphe, garde-fous, classifieur, pacer, parcours, calibration, simulateur, adaptateur Claude, FinOps, pilote)
```
